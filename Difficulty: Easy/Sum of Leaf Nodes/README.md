<h2><a href="https://www.geeksforgeeks.org/problems/sum-of-leaf-nodes/1?itm_source=geeksforgeeks&itm_medium=article&itm_campaign=practice_card">Sum of Leaf Nodes</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given the root of a binary tree, return the sum of the values of all its leaf nodes.<br></span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> root[] = [3, 1, 2]<br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/930734/Web/Other/blobid0_1783926195.webp" width="200" height="117"> <br><strong>Output: </strong>3<br><strong>Explanation</strong>: The sum of all the leaf nodes is: 1 + 2 = 3.</span></pre>
